## Featured work

### Language learning

#### [YT Dual Subs](https://github.com/aolingge/yt-dual-subs)

**Learn from videos you already watch.** Original captions and translations stay together on YouTube and Bilibili. Hover to look up words, follow the current word, replay difficult sentences, save expressions and export subtitles. For desktop Chrome and Edge; the README explains caption availability and translation providers.

[Install](https://github.com/aolingge/yt-dual-subs#install) · [中文说明](https://github.com/aolingge/yt-dual-subs/blob/main/README.zh-CN.md)

#### [DeutschOverlay](https://github.com/aolingge/DeutschOverlay)

**German captions for the audio playing on Windows 11.** Shows German speech as German and translates English or Chinese into German. Adjustable single-line or bilingual overlays, playback-device selection and local offline processing; optional Azure processing is documented separately.

[Download & setup](https://github.com/aolingge/DeutschOverlay#下载与安装) · [Releases](https://github.com/aolingge/DeutschOverlay/releases)

#### [deutsch-lernen](https://github.com/aolingge/deutsch-lernen)

**A German learning map for Chinese speakers.** A1–C1 routes connect listening, speaking, reading and writing with exam choices and preparation for Germany. The resource hub supports filtering, bookmarks and a study plan stored in the browser.

[Study routes](https://github.com/aolingge/deutsch-lernen/blob/main/docs/README.md) · [Resource hub](https://deutsch-lernen-resource-hub.pirostonelsonrx688.workers.dev/)

### Developer tools

#### [Agent Secret Guard](https://github.com/aolingge/agent-secret-guard)

**Focused safety checks for AI-agent repositories and MCP configurations.** Finds secret-like values, risky command arguments, exposed browser or credential-store references and overly broad GitHub Actions permissions. Text, JSON and SARIF output make findings easier to review locally or in CI.

[Quick start](https://github.com/aolingge/agent-secret-guard#quick-start) · [GitHub Action](https://github.com/aolingge/agent-secret-guard-action) · [Fix guide](https://github.com/aolingge/agent-secret-guard/blob/main/docs/remediation.md)

#### [Agent Reliability Kit](https://github.com/aolingge/agent-reliability-kit)

**A broader health report for repositories used with coding agents.** Reviews agent instructions, verification commands, README quality, CI permissions, tooling risks and release readiness. Produces Markdown, JSON and HTML reports; dedicated commands cover team audits, MCP registries and n8n workflows.

[Quick start](https://github.com/aolingge/agent-reliability-kit#quick-start) · [Documentation](https://aolingge.github.io/agent-reliability-kit/)

#### [MCP Config Doctor](https://github.com/aolingge/mcp-config-doctor)

**Find setup mistakes before an MCP client fails to connect.** Checks configuration structure, startup commands, environment settings and common secret leaks, with terminal, JSON and Markdown reports. Runs locally; diagnostics help with configuration but do not certify a server's safety.

[Quick start](https://github.com/aolingge/mcp-config-doctor#quick-start) · [Checks](https://github.com/aolingge/mcp-config-doctor#checks)
