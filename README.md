I build **language-learning apps** and **developer tools**: turn video and desktop audio into study material, organize German resources, and inspect repositories, MCP configurations and coding-agent runs.

## Start here

- **Learn German:** [watch with bilingual captions](https://github.com/aolingge/yt-dual-subs#install), [caption Windows audio](https://github.com/aolingge/DeutschOverlay#下载与安装), or [browse study resources](https://deutsch-lernen-resource-hub.pirostonelsonrx688.workers.dev/).
- **Work with coding agents:** [scan repository risks](https://github.com/aolingge/agent-secret-guard#quick-start), [check repository health](https://github.com/aolingge/agent-reliability-kit#quick-start), or [diagnose MCP setup](https://github.com/aolingge/mcp-config-doctor#quick-start).
- **Explore the collection:** [live bilingual portfolio](https://aolingge.github.io/open-source-portfolio/).

## Featured work

### Language learning

- **[YT Dual Subs](https://github.com/aolingge/yt-dual-subs)** — YouTube and Bilibili captions, hover lookup, word highlighting, sentence replay and saved phrases. Desktop Chrome / Edge.
- **[DeutschOverlay](https://github.com/aolingge/DeutschOverlay)** — German captions over Windows 11 audio, with English/Chinese-to-German translation. Local offline mode; optional Azure mode.
- **[deutsch-lernen](https://github.com/aolingge/deutsch-lernen)** — A1–C1 study routes and Germany preparation for Chinese speakers; a resource hub with filtering, bookmarks and study plans.

### Developer tools

- **[Agent Secret Guard](https://github.com/aolingge/agent-secret-guard)** — Check secret-like values, risky arguments and broad permissions. Text, JSON and SARIF reports; [remediation guide](https://github.com/aolingge/agent-secret-guard/blob/main/docs/remediation.md).
- **[Agent Reliability Kit](https://github.com/aolingge/agent-reliability-kit)** — Review instructions, verification commands, documentation, CI and release readiness. Markdown, JSON and HTML reports; [documentation](https://aolingge.github.io/agent-reliability-kit/).
- **[MCP Config Doctor](https://github.com/aolingge/mcp-config-doctor)** — Diagnose configuration structure, startup commands, environment settings and common secret leaks locally. [Checks](https://github.com/aolingge/mcp-config-doctor#checks).
