# Aolinge

我做语言学习和日常开发中用得上的工具：字幕应用、德语学习资料，以及帮助 AI Agent 稳定完成工作的开发工具。

[English](README.md) · 简体中文

## 精选项目

### 语言学习

| 项目 | 用途 |
| --- | --- |
| [yt-dual-subs](https://github.com/aolingge/yt-dual-subs) | YouTube 双语字幕，支持单词高亮、悬停查词、句子练习和短语收藏，适用于 Chrome 和 Edge。 |
| [DeutschOverlay](https://github.com/aolingge/DeutschOverlay) | Windows 德语实时字幕条，显示德语原文，也能把英语和中文翻译成德语。 |
| [qingjian-german](https://github.com/aolingge/qingjian-german) | 为轻简应用补充汉德释义和 CEFR 等级，提供构建脚本与验证记录。 |
| [deutsch-lernen](https://github.com/aolingge/deutsch-lernen) | 面向中文学习者的 A1–C1 德语资料，覆盖考试和赴德准备。 |

### 开发工具

| 项目 | 用途 |
| --- | --- |
| [agent-secret-guard](https://github.com/aolingge/agent-secret-guard) | 检查 AI Agent 仓库、MCP 配置和 GitHub Actions 中的凭据暴露与高风险设置。 |
| [agent-reliability-kit](https://github.com/aolingge/agent-reliability-kit) | 汇总 README、CI、安全检查和发布准备情况。 |
