- **浏览全部作品：**[中英双语在线作品集](https://aolingge.github.io/open-source-portfolio/)。

## 精选项目

### 语言学习

- **[YT Dual Subs](https://github.com/aolingge/yt-dual-subs)** — YouTube、Bilibili 双语字幕，支持悬停查词、单词高亮、难句重播和表达收藏。适用于 Chrome、Edge 桌面版。
- **[DeutschOverlay](https://github.com/aolingge/DeutschOverlay)** — 为 Windows 11 播放声显示德语字幕，支持英语、中文转德语。本地模式可离线处理，也提供可选的 Azure 在线模式。
- **[deutsch-lernen](https://github.com/aolingge/deutsch-lernen)** — 面向中文学习者的 A1–C1 路线与赴德准备；资源站支持筛选、收藏和学习计划。

### 开发工具

- **[Agent Secret Guard](https://github.com/aolingge/agent-secret-guard)** — 检查疑似凭据、危险参数与过宽权限，输出文本、JSON、SARIF 报告。[修复指南](https://github.com/aolingge/agent-secret-guard/blob/main/docs/remediation.md)。
- **[Agent Reliability Kit](https://github.com/aolingge/agent-reliability-kit)** — 检查 Agent 指令、验证命令、文档、CI 与发布准备，输出 Markdown、JSON、HTML 报告。[项目文档](https://aolingge.github.io/agent-reliability-kit/)。
- **[MCP Config Doctor](https://github.com/aolingge/mcp-config-doctor)** — 在本地诊断配置结构、启动命令、环境设置与常见凭据泄露。[检查范围](https://github.com/aolingge/mcp-config-doctor#checks)。
